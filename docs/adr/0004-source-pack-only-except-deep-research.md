# Source Pack only, except Deep Research may fetch public sources

Every Module works only from the Source Pack the analyst attached: anything missing is a gap named in cp-start so the analyst can add it before Approval, which keeps runs reproducible and keeps issuer names out of search engines. The one exception is Deep Research, whose job (market, competitors, regulation, sector, outlook) needs evidence an issuer pack rarely carries: it may fetch public sources, saving each fetched page into the run folder and citing URL and retrieval date, within research questions the analyst approved at cp-start. Model background knowledge is never evidence.

## Consequences

If the work VS Code build exposes no fetch or web tool, Deep Research degrades to pack-only and cp-start must say so before Approval.
