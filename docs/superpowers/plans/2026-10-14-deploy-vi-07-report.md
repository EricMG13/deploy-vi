# Deploy VI Plan 07 — Report renderer (draft, 2026-10-14)

> **For agentic workers:** execute task-by-task with `superpowers:subagent-driven-development`; one fresh implementer per task, the controller re-runs gates. No copied code-replay blocks (owner amendment 2026-10-13).

**Goal:** `rbot render --run <RUN>` turns a finished run into `report.html` (one self-contained file in the frozen Report A template) and `report.md`, embeds the `rbot-run/1` JSON, writes the `report` fields of `run-state.json` through the state engine, and the orchestrator's `done` branch calls it.

**Architecture (one sentence):** Python owns every byte of content (a view model built from the run, rendered to static HTML and Markdown, fully testable under pytest); the frozen template's own CSS and `charts.js` (RBOTCharts + RBOTUI) are shipped verbatim and a new, generic `report.js` enhances the static page (shell behaviour, popovers, scale badges, status chips, chart mounting) — because the mockup's `report-a.js` is not a template at all but a CZR-specific page script (see D1).

**Tech:** Python ≥ 3.11 stdlib only (`string.Template`, `html`, `json`, `hashlib`, `decimal`); no new runtime dependency. Repo root is the Plan 07 worktree; paths below are relative to it.

## Decisions

- **D1 — the mockup is not data-driven; only its shared layer is.** `design/mockups/report-a.js` (1,724 lines) builds the page from `window.RBOT_DATA`, a bespoke schema produced by `build-data.py` from `czr.json` (figures keyed `opm_*`, `issuer.ceo`, hard-coded headline strings with `{C94|US$ m}` tokens, a `GAP_LABEL` map, CZR committee questions). It throws on any other dataset. It cannot be reused as the renderer. `shared/charts.js` (RBOTCharts: `lineStrip`, `columns`, `waterfall`, `bullet`, `stackedColumns`, `rangeStrip`, `scatter`, `dumbbell`, `riskMatrix`; RBOTUI: popover, `cell`, `value`, `chip`, `scale`, `status`, `roving`, `tabs`) and the two CSS files are generic and are reused verbatim. The reusable, generic ~700 lines of `report-a.js` (routing, search, contents line, Key popover, collapse/expand, mobile menu, print) are lifted into the new `report.js`.
- **D2 — Python renders, the template enhances.** `rbotlib/report/` builds a view model from the run and emits static HTML using the template's classes (`.bar`, `.block`, `table.dt`, `details.xp`, `.status--*`, `.scale`, `.cite`, `.gap`, `.pop`), plus `report.md` from the same model. `report.js` upgrades `[data-scale]` → `RBOTUI.scale`, `[data-status]` → `RBOTUI.status`, `td[data-datum]` → `RBOTUI.cell`, `a.cite[data-ref]` click → `RBOTUI.open`, `figure[data-chart]` → `RBOTCharts.<kind>`. Without JS the page is still complete (tables, table twins, anchors) — which is what the Python tests assert.
- **D3 — charts are drawn by `charts.js` from specs Python emits.** `rbotlib/report/charts.py` builds, per chart, the RBOTCharts spec (`data`), the table twin, the summary line and the origin; no SVG in Python (Ruling R1). RBOTUI's popover reads `window.RBOT_DATA.{citations,calcs,gaps}` keyed by ref; `report.js` derives that map from the embedded `rbot-run/1` JSON, so the JSON stays exactly §11.3.
- **D4 — one run → one JSON.** `run_json.py` assembles `rbot-run/1` from `run-state.json` (read through `state.read`, which refuses legacy/unowned runs), every `handoffs/*.md` the state lists as accepted or blocked (bytes re-hashed against `steps.<id>.sha256`), `validate/<ID>.json` (anchored flags), `run-brief.md`, `model.json`, `fit/*.json`, `rbot/catalog.json` blocks and the module contracts. Absent/failed/skipped modules carry only their step record and reason.
- **D5 — state fields are written by `state.update`** with a `publish` callback (the `next.select` pattern): the files are written atomically under the Approval lock, then `report.written_at/html_sha256/md_sha256` are staged and committed. No other writer; no evidence keys touched.
- **D6 — frozen assets move, they are not copied.** `git mv` of `tokens.css`, `report-a.css` (→ `report.css`) and `charts.js` into `rbot/report/` is a pure rename (0 lines in `git diff --numstat`); copying 2,370 lines cannot pass the 800-line gate (`charts.js` alone is 1,323 lines) and AGENTS.md forbids new cap exemptions. The four mockup HTMLs keep working via updated relative links (`../../rbot/report/…`). Confirm with `bash scripts/check_pr_size.sh` on the branch before the task closes.
- **D7 — fonts and logo.** No Inter/Inter Tight files exist in the repo and the renderer must not fetch. v1: the CSS font stacks fall back to `system-ui`; when `rbot/report/fonts/*.woff2` exist (owner-supplied, OFL) the renderer inlines them as base64 `@font-face`. The logo ships as `rbot/report/logo.png` (a copy of `brand/ssim-logo-horizontal-white.png`, 17 KB, inlined as a data URI). Recorded in `docs/decisions/0005-report-assets.md`.

## Shared interfaces

```
rbot/report/                      shipped assets (installed with the skill; hashed by runtime.json)
  tokens.css  report.css  charts.js  report.js  logo.png  [fonts/*.woff2]
rbot/scripts/rbotlib/report/
  __init__.py   assets.py   run_json.py   blocks.py   charts.py   html.py   markdown.py   render.py
tests/test_report_assets.py  test_report_run_json.py  test_report_blocks.py  test_report_charts.py
tests/test_report_html.py    test_report_markdown.py  test_report_render.py  test_render_corpus.py
tests/report_run.py (helper: a complete native run from fixture Handoffs)
```

- `class ReportError(ValueError)` (`run_json.py`): every refusal; `render` prints `error: <path>: <reason>` and exits 1.
- `Record = dict[str, Any]` as in `state.py`. `Datum = {"v": str|None, "prov": "cited"|"calculated"|"model"|"gap", "ref": str|None, "reason": str|None}`; `ref` is `"<MODULE>:C<n>"` for a citation, `"MODEL:<line_id>:<column_id>"` for a Model cell passport, `"MODEL:gap:<line_id>:<column_id>"` for a Model gap.
- `rbot-run/1` as §11.3 with R10/R13; `front_page` = the Pathway's front page id; `handoffs` includes `MODEL` and `FIT`; `model` = `model.json` or `null`; `fit` = `[fit/<id>.json …]`; `prior_case` = `{"report": null, "report_date": null, "diff": null}` in v1.
- Chart entry: `{"chart_id","where","kind","origin","tables":[ids],"data":{RBOTCharts spec},"twin":{"columns":[…],"rows":[[…]]},"summary":str,"note":str|null}`; an undrawable chart has `"data": null` and `"note"` naming the missing input (the template's n/a frame).
- Block entry: `{"id","title","shown":bool,"reason":str|null,"line":str|null,"tables":[{"table_id","owner","status","columns","rows"}],"charts":[chart_ids]}`.

### Task 07.2 — `run_json.py`: the `rbot-run/1` assembly and its refusals
**Goal:** one pure-ish reader turns a finished, owned run into the embedded JSON.
**Files:** `rbot/scripts/rbotlib/report/run_json.py`; `tests/test_report_run_json.py`; `tests/report_run.py` (helper, see 07.8 — written here because 07.2's integration test needs it; corpus-marked).
**Interfaces:**
- `build(run: Path, root: Path, generated_at: str) -> Record` — the §11.3 document without `charts`/`front_page_blocks` (filled by 07.3/07.4).
- `handoff_entry(run: Path, module: str, step: Record, validation: Record | None) -> Record` → `{sha256, qa_status, status, front_matter, analysis_md, gaps_md, tables: {id: {columns, rows}}, citations: [{id, source, locator, excerpt, anchored}]}`; `analysis_md`/`gaps_md` are the raw section bodies (`handoff.parse` sections; fenced code kept verbatim).
- `anchored(validation: Record | None, cid: str) -> bool | None` — `False` when a `citation_unanchored`/`source_unknown` finding names `cid` (message prefix `"<cid>: "` or the source), `True` when the validation exists without such a finding, `None` when no `validate/<ID>.json` exists (receipt-free CP-0).
- `public_step(step: Record) -> Record` (R10). `limitations(record, brief, handoffs, model) -> {"approval": [...], "cp5": [rows], "unforeseen": [...]}` per §11.2 tab 8 (approval: `brief.approval.limitations_shown` + `grading.json` `limited_modules`; unforeseen: failed/skipped steps with reason, Blocked Handoffs, `model.limitation_details`, unanchored citations).
**Behaviour / refusals (all `ReportError`, message names the path):** `approval is None` → `render requires Approval`; any step `pending`/`running` → `render requires every step terminal: <ids>`; accepted/blocked Handoff whose bytes hash ≠ `steps.<id>.sha256` → `handoffs/<id>.md changed since acceptance; run next to re-validate`; `MODEL` accepted but `model.json` missing/invalid JSON/`schema != rbot-model/1` → named; `FIT` accepted but `fit/` holds no JSON for a `brief.portfolios` row → named; Handoff unparseable (`HandoffError`) → named; `run-brief.md` unparseable → named. A `failed`/`skipped` step contributes no Handoff entry (its reason is on the step). Legacy/unowned runs are refused by `state.read` before any read of the run.
**Tests:** `test_build_matches_schema_on_complete_fixture_run` (corpus; every plan step present; `handoffs` has all 11 ids; `generated_at` is the only field that changes between two builds), `test_refuses_unapproved`, `test_refuses_non_terminal[pending,running]`, `test_refuses_changed_handoff_bytes`, `test_refuses_missing_model_json_when_model_accepted`, `test_failed_and_skipped_steps_carry_reason_only`, `test_anchored_flags[found,unanchored,no_validation]`, `test_public_step_strips_evidence_keys` (a step with `accept_history`, `current_edits`, base64 evidence → only the twelve public keys), `test_blocked_handoff_embeds_gap_cells`.
**Estimate:** ~620 lines (run_json ~300; helper ~90; tests ~230).

### Task 07.3 — `blocks.py`: Front Page blocks from catalog `blocks`
**Goal:** the 18 `credit_snapshot` blocks resolve to owner, rows, condition and refusal lines.
**Files:** `rbot/scripts/rbotlib/report/blocks.py`; `tests/test_report_blocks.py`.
**Interfaces:**
- `owner_of(table_id: str, record: Record, catalog: Catalog, contracts: Mapping[str, Contract]) -> str` — `catalog.host_tables` first (`RUN_BRIEF` tables read from `run_brief.tables`), else the one plan module whose contract lists the table; zero or two owners → `ReportError` (never, `rbot check` prevents it).
- `CONDITIONS: dict[str, Callable[[Record], bool]]` = `always` → True; `primary` → `run["primary"] is True`; `portfolios` → `run_brief.tables["brief.portfolios"].rows` non-empty. Any other catalog condition → `ReportError("condition <c> not supported by this renderer")` (Plans 10–13 add them). Reason strings: `Transaction summary: not a Primary run`, `Portfolio Fit: no portfolio attached`.
- `front_page_blocks(run: Record, catalog: Catalog, contracts) -> list[Record]` (block entry, shared interfaces). A table whose owner is `failed`/`skipped` gives `line = "<title>: <module> <status> — <reason>"` and `tables=[]`; a Blocked owner renders its tables (gap cells `—`) and `line = "<module> Blocked"`; a missing table in an accepted Handoff → `ReportError` (the validator guarantees presence).

- `format_number(text: str, money: bool) -> str`: inserts thousands separators into a plain decimal string only (`^-?\d{4,}(\.\d+)?$`), never changes digits; applied to `amount`, `outstanding`, `size`, `market_value`, financial slot columns.
**Tests (hand-built `run` dicts; no corpus):** `test_every_catalog_block_has_one_owner`, `test_primary_condition_lines[true,false]`, `test_portfolios_condition`, `test_unsupported_condition_refuses`, `test_failed_owner_renders_one_line_with_reason`, `test_skipped_owner_line_names_input`, `test_blocked_owner_keeps_tables`, `test_capital_structure_join_fills_dashes`, `test_call_band_from_fixture_handoffs` (parses `tests/fixtures/handoffs/CP-2.md`, `CP-6.md`), `test_format_number_never_changes_digits` (hypothesis: digits of output == digits of input; years and ids untouched).

### Task 07.5 — `html.py`: the static Report A page
**Goal:** `render_html(run, blocks, charts, assets) -> str` emits the complete self-contained page.
**Files:** `rbot/scripts/rbotlib/report/html.py` (split helpers into `html_blocks.py` if complexity needs it); `tests/test_report_html.py`.
